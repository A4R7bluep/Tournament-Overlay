# Tournament-Overlay

## How To Use

It is designed to be used with OBS. I suggest using two window captures, 
one for the game and one for the overlay, with the game capture behind the overlay.

### Overlay Window's Controls:

- Left/Right Player Score Increase: Numpad 7/9
- Left/Right Player Score Decrease: Numpad 4/6
- Reset Scores: Numpad 8
- Swap Names: Numpad 5
- Set Name Forward: Numpad 3
- Set Name Backward: Numpad 1
- Open Settings Window: Numpad 2

## About

I made the overlay mostly because I wanted something I could use for myself, 
but also something streamlined for other people to use, especially if they have 
a single monitor like I currently do.
